A modern reimagination of the Ray-Ban landing page focused on bold visual storytelling, luxury-fashion aesthetics, and immersive frontend design.

This project was built as a frontend design exploration to recreate the premium feel of high-end eyewear campaigns while adding my own artistic direction and layout decisions.

ㅤㅤㅤㅤㅤ
### Design Philospohy 

Rather than creating a pixel-perfect clone, this project was approached as a creative reinterpretation of the Ray-Ban visual identity. The goal was to capture the bold, cinematic, and fashion-oriented energy commonly seen in luxury eyewear campaigns while introducing a more experimental and modern frontend presentation.

The design emphasizes strong visual hierarchy, oversized editorial typography, immersive color composition, and mood-driven UI decisions to create a landing page that feels premium and visually engaging. Every section was structured to balance aesthetics with user attention flow, allowing the interface to feel less like a conventional ecommerce page and more like a digital fashion campaign.

This project also served as an exploration of branding consistency, frontend creativity, and modern interaction-focused web design principles.
